# FUTURE_DS_03
## About This Project

This project analyzes a 120,000-session Direct-to-Consumer (D2C) e-commerce marketing funnel dataset covering the period from July to December 2025. The goal was to evaluate customer behavior across the entire purchase journey—from website sessions and cart additions to checkout completion and purchases—and identify opportunities to improve conversion performance and revenue growth.

The raw dataset was first cleaned and transformed using Python and Pandas, including date standardization, binary value conversion, and customer journey classification. The cleaned data was then imported into Excel, where key business metrics such as Conversion Rate, Average Order Value (AOV), Cart Abandonment Rate, Revenue, Purchases, and Checkout Conversion Rate were calculated and analyzed.

An interactive Excel dashboard was developed to provide a comprehensive view of marketing and sales performance across multiple dimensions, including Channel, Campaign, Device Type, Region, Discount Usage, Customer Type, and Monthly Trends. The dashboard contains KPI cards, PivotTables, PivotCharts, summary tables, and slicers that enable users to dynamically explore performance drivers and identify areas for optimization.

### Excel Features Used

* PivotTables for KPI calculations and performance summaries
* PivotCharts for funnel, trend, channel, campaign, and revenue visualizations
* COUNTA, SUM, percentage calculations, and logical formulas for KPI metrics
* IF and Nested IF formulas for customer journey classification
* Number Formatting for currency, percentages, and KPI presentation
* Conditional Formatting for KPI cards and performance highlighting
* Slicers for interactive filtering by Month, Channel, Campaign, Device, Region, and Discount
* Auto Filters for data exploration and validation
* Freeze Panes for easier navigation of large datasets
* Custom chart formatting including data labels, colors, legends, and titles
